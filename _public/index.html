Four Variants

Each one comprised of 48 colors and focused on an accent color. An inverse accent is used for things that require your attention. This includes selected text, highlighted by the visual selection color.

Most of the palette stays the same between variants, only background colors differ in order to maintain consistecy while giving each variant its own atmosphere.

struct Point {

  x: f64,

}


impl Point {

  // Calculate the difference and square root

  fn calc(&self, other: &Point) -> f64 {

    (self.x - other.x).abs().sqrt()

  }

}


fn main() {

  let p = Point { x: 4.0 };

  println!("Calc:{:.2}", p.calc(&Point { x: 2.0 }));

}

Colorful contrast

Nevergrove provides the calmness of desaturated backgrounds proved great by other palettes, while tuning up the intensity of foreground colors. Colors neither too pale nor too bright, vibrant but not overwhelming.

Coding clarity

Nevergrove is a programming palette first. Syntax highlighting makes reading code easier, your color palette should help, not interfere.

Sharper syntax

The readability of a color theme also depends on the use it makes of its colors. Nevergrove keeps color harmony in mind, but prioritizes readability when needed so elements that should stand out do so.
Harness the power of the rainbow, find what you need at a glance.

Avoid transparency

Transparency offers huge possibilities, but I find more often that not it also makes themes inconsistent. A palette should foster creativity through constraints.

No AI was used in the creation of the Nevergrove palette, this site, or any of the official Nevergrove themes.
